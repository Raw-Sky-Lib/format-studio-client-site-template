# LINEAR-SETUP.md — Client Site Template
> Reusable Linear project file for every client site built from this template.
> Fill in all `{{PLACEHOLDERS}}` before importing. Remove optional sections that don't apply.
>
> Import into Linear via: Settings → Import → CSV Import
> Save the CSV block at the bottom as `{{CLIENT_SLUG}}-linear-import.csv`

---

## How to Use This File

1. **This file is generated by Claude** during the project kickoff workflow. Review and edit as needed.
2. **Decide which optional modules apply** (Blog, Portfolio) and delete the ones you won't build.
3. **Create the Linear team** using the Workspace Setup section.
4. **Import issues** using the CSV block at the bottom.
5. **Delete this "How to Use" section** after setup is done.
